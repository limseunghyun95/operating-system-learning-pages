하나의 요청을 끝까지 추적하는 과정

각 계층은 성능과 실패의 책임이 다릅니다. 매일 학습자료는 아래 경계 중 어디에서 상태가 바뀌는지 먼저 표시합니다.

Application함수 호출, thread, runtime 상태
Library/Runtimebuffering, allocator, syscall wrapper
Kernelscheduler, VM, VFS, socket
Driverqueue, interrupt, DMA
HardwareCPU, MMU, cache, memory, device

매일 답해야 하는 네 가지 질문

무엇이 상태인가?

register, address space, file offset, run queue처럼 저장·복원되거나 공유되는 상태를 찾습니다.

경계는 어디인가?

user/kernel, process/thread, virtual/physical, buffered/durable의 경계를 구분합니다.

실패하면 무엇이 남는가?

partial write, zombie, dirty page, leaked descriptor처럼 복구에 필요한 증거를 봅니다.
